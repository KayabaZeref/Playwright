# Playwright Guide from Codemify YouTube

This repository contains notes and samples for learning Playwright from the Codemify YouTube guide.

## Overview

- Browser automation with Playwright
- Following tutorial steps from Codemify
- Practice scripts for web testing and automation

## Getting Started

1. Install dependencies:
   ```bash
   npm install playwright
   ```
2. Run a sample script:
   ```bash
   npx playwright test
   ```

## Notes

- Use Chromium, Firefox, or WebKit browsers
- Keep tests simple and readable
- Use selectors and assertions from the guide
